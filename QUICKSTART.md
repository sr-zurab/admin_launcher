## 1️⃣ Десктоп (Python) — 2 минуты

```bash
# 1. Перейдите в папку проекта
cd /home/zurab/My\ projects/admin_launcher

# 2. Активируйте venv (уже создан)
source venv/bin/activate

# 3. Запустите
python main.py
```

**Готово!** Откроется окно с вкладками: **ГМУ**, **Бюджет**, **Сертификаты**, **Лаунчер**.

### Данные уже есть
Ваши JSON-файлы (`data.json`, `db.json`, `organizations.json`) уже используются программой.

## 2️⃣ Браузерное расширение — 3 минуты

### Установка в режиме разработчика

**Chrome / Edge / Vivaldi / Brave / Opera:**
```
1. Откройте chrome://extensions
2. Включите "Режим разработчика" (правый верхний угол)
3. Нажмите "Загрузить распакованное расширение"
4. Выберите папку: browser_extension/dist
```

**Firefox:**
```
1. Откройте about:debugging
2. "Это Firefox" → "Временное расширение"
3. Выберите: browser_extension/dist/manifest.json
```

### Проверка
- Нажмите на иконку расширения → откроется **Popup** с быстрым поиском
- Нажмите кнопку "🔍" в попапе или правый клик → "Открыть AdminLauncher" → откроется **Side Panel**

---

## 3️⃣ Импорт ваших JSON-баз в расширение — 1 минута

1. Откройте **Настройки** расширения:
   - В попапе: ссылка "Настройки"
   - Или: `chrome-extension://<ВАШ_ID>/options.html`

2. Перейдите на вкладку **"Данные"**

3. В разделе **"Импорт из исходного проекта"**:
   - Выберите `data.json` → нажмите **"Импортировать ГМУ"**
   - Выберите `db.json` → нажмите **"Импортировать Бюджет"**
   - Выберите `organizations.json` → нажмите **"Импортировать Организации"**

4. Данные появятся во вкладках **ГМУ** и **Бюджет** в Side Panel

---

## 4️⃣ Настройка сертификатов (Windows) — 2 минуты

**Требуется для работы с хранилищем сертификатов через расширение.**

### Получите Extension ID
1. `chrome://extensions` → найдите AdminLauncher
2. Скопируйте **ID** (32 символа, напр. `abcdefghijklmnopqrstuvwxyz123456`)

### Установите Native Host
```powershell
# PowerShell от АДМИНИСТРАТОРА
cd browser_extension/native_host
.\install_windows.ps1 -AllUsers -ExtensionId "ВАШ_ID_ЗДЕСЬ"
```

### Проверка
1. Перезапустите браузер
2. Side Panel → Настройки → Сертификаты → **"Проверить Native Host"**
3. Должно показать: `✅ Native Host работает. Доступные хранилища: MY, ROOT, CA...`

## 🔍 Основные сценарии использования

### Поиск организации по ИНН (ГМУ)
1. Side Panel → вкладка **ГМУ**
2. Введите ИНН (10 или 12 цифр) → Enter
3. Результат: реквизиты, Л/С (авто 20946...), классификаторы, руководитель, учредитель
4. Кнопки: **Копировать ИНН**, **Экспорт CSV**, **Открыть на bus.gov.ru**

### Поиск в Бюджете (УБП/НУБП)
1. Вкладка **Бюджет**
2. ИНН → "По ИНН" или Название → "По наименованию"
3. Вкладки деталей: **Информация**, **Лицевые счета**, **Каз. счета**, **Руководители**, **Учредители**

### Работа с сертификатами
1. Вкладка **Сертификаты** → **"Обновить"**
2. Фильтры: **Все / Действительные / Просроченные**
3. Цвета: 🔴 просрочен, 🟡 ≤30 дней, 🟢 ок
4. Детали: CN, ИНН, СНИЛС, ОГРН, SHA1/256, сроки, контейнер
5. Экспорт: **PEM** / **PFX** (через Native Host)

### Контекстное меню на любом сайте
1. Выделите ИНН на странице
2. Правый клик → **"Найти в ГМУ"** или **"Найти в Бюджете"**
3. Откроется Side Panel с результатом

## 🔄 Синхронизация Desktop ↔ Extension

| Направление | Как сделать |
|-------------|-------------|
| **Desktop → Extension** | Options → Данные → Импорт JSON файлов |
| **Extension → Desktop** | Options → Экспорт всего (JSON) → положите файлы в папку проекта |
| **Extension → Extension** | Options → Экспорт всего → Импорт на другом компьютере |

## ❗ Типичные проблемы и решения

| Проблема | Решение |
|----------|---------|
| Расширение не загрузилось | Проверьте, что выбрали папку `dist`, а не `src` |
| Native Host не найден | Запустите `install_windows.ps1` от админа, перезапустите браузер |
| Сертификаты не грузятся | Проверьте в Options → Сертификаты → "Проверить Native Host" |
| API ошибка 403/CORS | Используйте Side Panel (идёт через background), не content script |
| Данные пропали | Options → Опасная зона → "Полностью сбросить" (осторожно!) |
