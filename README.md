# Инструменты администратора (Admin Launcher)

Набор инструментов для работы с ГИС, сертификатами и данными организаций. Графический интерфейс на PyQt6.

## Возможности

| Приложение | Описание |
|------------|----------|
| **Инфо по организациям bus.gov.ru** | Получение информации об учреждении через API bus.gov.ru, экспорт в Excel |
| **Менеджер сертификатов** | Управление сертификатами ЭЦП |
| **Импорт ЕГРЮЛ из PDF** | Парсинг PDF выписок ЕГРЮЛ/ЕГРИП и сохранение данных |
| **Реестр УБП/НУБП из ЭБ** | Работа с реестром пользователей бюджетных полномочий |

---

## Требования

- Python 3.10+
- Linux (основная целевая ОС) / Windows / macOS
- Установленные системные зависимости Qt6 (на Linux: `libqt6widgets6`, `libqt6gui6` и др.)

---

## Установка

### 1. Клонирование и вход в папку

```bash
git clone <repository-url>
cd admin_launcher
```

### 2. Создание виртуального окружения

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

---

## Запуск

### Вариант 1: Прямой запуск Python

```bash
source venv/bin/activate
python launcher_ddo.pyw
```

### Вариант 2: Интеграция в меню приложений Linux

Создайте `.desktop` файл в `~/.local/share/applications/` с содержимым:

```ini
[Desktop Entry]
Version=1.0
Type=Application
Name=Инструменты администратора
Comment=Комплекс приложений для работы с ГИС и сертификатами
Exec=/путь/к/проекту/venv/bin/python /путь/к/проекту/launcher_ddo.pyw
Path=/путь/к/проекту
Terminal=false
Icon=/путь/к/проекту/Icon.png
Categories=Utility;Application;
StartupNotify=true
```

Замените `/путь/к/проекту` на реальный путь. После этого приложение появится в меню.

```
admin_launcher/
├── launcher_ddo.pyw      # Главное окно запуска (точка входа)
├── gmu_information.py    # Модуль: Инфо по организациям bus.gov.ru

├── budget.py             # Модуль: Реестр УБП/НУБП
├── requirements.txt      # Зависимости Python
├── *.ico, *.png          # Иконки приложений

```

## Основные действия

- Все окна приложений работают **независимо** — можно открыть несколько одновременно
- Меню «Справка → О программе» — версия лаунчера
- Кнопки имеют подсказки (tooltip) при наведении

## Данные и конфигурация

При работе модулей автоматически создаются файлы с данными (кэш организаций, сохранённые аккаунты, ответы API и др.). Они не требуют ручного редактирования.

---

## Устранение проблем

| Проблема | Решение |
|----------|---------|
| `ModuleNotFoundError: PyQt6` | Активируйте venv: `source venv/bin/activate` и выполните `pip install -r requirements.txt` |
| Ошибки Qt при запуске на Linux | Установите системные пакеты Qt6: `sudo apt install libqt6widgets6 libqt6gui6 libqt6core6` (Debian/Ubuntu) |
| Иконки не отображаются | Проверьте наличие файлов `*.ico`, `*.png` рядом с `launcher_ddo.pyw` |
