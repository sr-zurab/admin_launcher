# Инструменты администратора

Комплекс приложений для работы с ГИС и сертификатами.

## Запуск
Для запуска приложения используйте скрипт `run.sh`:
```bash
./run.sh
```

## Перенос на другой компьютер
Чтобы перенести приложение на другой компьютер:

1. **Скопируйте папку** целиком на новый компьютер.
2. **Создайте виртуальное окружение** (внутри папки приложения):
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```
3. **Установите зависимости**:
   ```bash
   pip install -r requirements.txt
   ```
4. **Установите права на исполнение**:
   ```bash
   chmod +x run.sh
   chmod +x admin_launcher.desktop
   ```
5. **Ярлык**: Для удобства скопируйте `admin_launcher.desktop` в `~/.local/share/applications/` на новом компьютере (при необходимости исправьте путь внутри файла).
